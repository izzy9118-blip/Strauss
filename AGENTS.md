Read `STRAUSS.md` before using this repository as a harness.

When the user opens, mounts, activates, or turns on the Strauss harness, load the
Custos Strauss Reader immediately. Run `python adapter.py` to obtain its current
instructions and both gates alongside Strauss's ministerial context. Read and apply
the returned `reader.instructions` and `reader.gates` during source examination.

Custos is the active reading authority. Do not substitute attached historical boot
sequences, an older Reader, or Strauss's ministerial reporting rules for it. A user
supplied source or registered inquiry is the explicit input; there is no global
default inquiry. See `STRAUSS.md` for executable and conversational reading.
