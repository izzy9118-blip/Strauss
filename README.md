# Strauss

Start with [STRAUSS.md](STRAUSS.md). Opening or activating this harness loads the
[Custos Strauss Reader](https://github.com/izzy9118-blip/custos), its full current
instructions, the five-stage documentary protocol, and the 22 literary techniques.

```bash
python adapter.py --pretty
```

Use `--source` or `--inquiry` for reading. Close mode is the default; `--mode sweep`
maps a whole supplied text. Executable reading requires `--reasoner-command` and is
delegated to Custos. The conversational reasoner applies the same loaded instructions.

Strauss's corpus, foundational problems, and ministerial reporting remain governed by
[manifest.yaml](manifest.yaml). Reader results retain their documentary status and do
not automatically become admitted findings.
